# Support

This repository is public so the audit records, verifier, and standards work can be
read and checked independently. It is not a free advisory channel.

## Bugs and questions about the code

Open a GitHub issue for defects in the verifier CLI, the SDKs, the OCSF or CoSAI
mapping documents, or anything else in this repository. Include the command you
ran, the output you got, and the output you expected.

Security reports follow [SECURITY.md](SECURITY.md), not the issue tracker.

## Help with your own system

Requests for architecture guidance, audit readiness, evidence design, OCSF
adoption, or "can you look at what we built" are advisory engagements, and all
advisory engagements are paid. Start here:

https://www.ai-identity.co/request-services

The form asks for the service you want, your timeline, and a budget range, and it
delivers straight to the founder. Email sent without that context is answered by
pointing you to the same form.

## Verifying our evidence

You do not need to contact anyone to check an AI Identity audit record. The
verifier in [`cli/`](cli/) is MIT licensed and runs offline; the README shows the
three commands.
